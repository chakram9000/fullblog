# Fullblog

Monorepo for a fullstack web blog application, with a public and a CRUD admin/author front.

<img width="1919" height="1079" alt="image" src="https://github.com/user-attachments/assets/64506b0b-6c1c-4fbc-930d-8a4f6f81c9b9" />

Authors post, edit, delete, publish and unpublish posts, while guests can read them, and users with an account can also like and comment.

## Tech stack

__API__: Hono, Prisma, Zod, PostgresQL.
__Frontends (SPA)__: Vite, React, Tanstack, Tailwindcss, Zustand.
